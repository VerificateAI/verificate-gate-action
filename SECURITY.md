# Security policy

## Reporting a vulnerability

Please report security issues **privately** — do not open a public issue or pull request.

1. Preferred: use GitHub's private reporting for this repository — **Security → Report a vulnerability**.
2. Or email **info@verificate.ai** with the subject line `SECURITY`.

Include what you found, how to reproduce it, and the impact you believe it has. Please do not include other
people's data, and do not run tests that degrade the hosted service for other users.

## What to expect

- Acknowledgement within **3 business days**.
- An initial assessment (accepted / need more detail / not a vulnerability) within **10 business days**.
- We keep you informed until the fix is released, and credit you in the advisory unless you prefer otherwise.
- Fixes are published through GitHub Security Advisories for the affected repository.

## Scope

- The code in this repository.
- The hosted Verificate Gate endpoint `https://mcp.verificate.ai/mcp` and the account service behind
  `https://verificate.ai/auth/*`.

Out of scope: volumetric denial of service, social engineering, findings that need a compromised machine or
account, and reports generated by automated scanners without a demonstrated impact.

## Supported versions

Only the latest released version receives security fixes. The hosted service is always the current version.

## Safe harbour

Good-faith research that follows this policy, avoids privacy violations and service disruption, and gives us
reasonable time to fix an issue before disclosure will not be pursued legally by Verificate.
